# G8 figures: previews

This research was supported by data provided by Meituan.

These PNGs are Python previews, marked PREVIEW. The paper figures render in MATLAB on CT 315 from the same CSVs (`figures/forest_plot_extension.m` reads the analysis's `contrasts.csv`; `figures/w1_over_time_extension.m` reads `w1_over_time_extension.csv`). Colors: one fixed slot per model from a validated colorblind-safe palette, with marker shapes as a second cue.
